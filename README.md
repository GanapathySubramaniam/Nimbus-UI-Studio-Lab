# Nimbus UI Studio Lab

Nimbus UI Studio Lab is an open-source React component system and interactive laboratory for enterprise agentic-AI applications.

The project will provide framework-neutral packages, Vite and Next.js reference applications, a governed white-label theme Studio, accessible agent conversation patterns, human-in-the-loop approvals, result and artifact surfaces, protocol adapters, and enterprise administration experiences.

## Status

Nimbus is in foundation development. Public APIs are not stable until the coordinated 1.0 release.

## Principles

- Accessible behavior before styling convenience.
- User control before agent autonomy.
- Visible progress without private chain-of-thought.
- Semantic design tokens instead of hard-coded visual values.
- Stable internal contracts around evolving external protocols.
- Treat agent-produced content as untrusted.
- Issue-to-branch-to-pull-request traceability for every product change.
