## Preset token data: VoltAgent awesome-design-md

The 74 company-inspired presets in `packages/application-shell/src/studio/presets.ts`
derive selected style values from the design analyses in
[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md).

- Source commit: [`8147538b4226ae41e2487a9179e3bcc1f68e8554`](https://github.com/VoltAgent/awesome-design-md/commit/8147538b4226ae41e2487a9179e3bcc1f68e8554).
- Source directory: [`design-md/`](https://github.com/VoltAgent/awesome-design-md/tree/8147538b4226ae41e2487a9179e3bcc1f68e8554/design-md).
- Source license: [MIT](https://github.com/VoltAgent/awesome-design-md/blob/8147538b4226ae41e2487a9179e3bcc1f68e8554/LICENSE), reproduced in full below.
- Local source snapshot reviewed: September 6, 2026.

This revision contains 74 source folders with a `DESIGN.md`, producing 75
presets including the original Nimbus default. Nimbus has no third-party
source; its `source` field is empty. All other source fields link directly to
the corresponding analysis at the recorded commit.

The derived data selects documented palettes, card or control radii, spacing,
and typography values for the supported widget fields. Each preset represents
one coherent surface treatment where the source describes multiple modes.
The descriptions are newly written. Proprietary typefaces are replaced by
system sans, serif, or monospace categories; Claude and WIRED use the serif
editorial register described in their analyses. Intermediate source font weights
are retained where supported by the widget model, with rendering dependent on
the system font. Translucent hairlines are composited over the selected
background and stored as opaque six-digit hex. Shadow styles are reduced to
the studio's supported categories.

The source analyses remain outside the application. No source analysis prose,
Markdown documents, logos, photographs, or font files are bundled. Company and
product names identify the inspiration only; the presets are independent
interpretations and do not imply affiliation, approval, or endorsement.
The MIT notice below applies to the derived reference data.
